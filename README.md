# Autoboot-Tweepy

Bot automatizado para gestión de cuentas de Twitter/X. Automatiza publicaciones, seguimientos e interacciones usando Tweepy.

## 🚀 Características

- Publicación automatizada de tweets
- Gestión de seguimientos y seguidores
- Programación de contenido
- Monitoreo de interacciones

## 🛠️ Stack

- Python + Tweepy (Twitter API v2)
- Scheduling automatizado
- Logging y métricas

## 📦 Instalación

```bash
pip install -r requirements.txt
python main.py
```
